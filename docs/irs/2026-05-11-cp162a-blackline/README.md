## Lessons learned — apply to 2026 going forward

1. **Form 1065 is due March 15**, not April 15. The partnership filing deadline is one month earlier than the 1040 deadline. Calendar it.
2. **If running late, file Form 7004 by 3/15** for an automatic six-month extension to 9/15. It's free, takes minutes via TaxAct Business, and would have eliminated this entire incident.
3. **The IRS sometimes auto-abates** first-year entities with clean profiles. Don't pay penalty notices reflexively — give the abatement transcript check time to run before mailing money.
4. **TaxAct Business is the tool for 1065** — FreeTaxUSA does not support partnership returns. Save this in [[project_blackline_structure]] so it's not relearned.
